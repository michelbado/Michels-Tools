Monitoring is running. Everything is greyed out except Stop and I notice a problem now, and nobody else can start Monitor mode until you press Stop.

This is not a speed test. It judges two things separately:

  • Speed: how long answers from Michel's Tools take. A far-away link can be slow and still perfect.
  • Quality: how steady and complete the link is. Delays that jump around, answers that get lost, freezes and drop-outs are what ruin calls, video and page loads.

About five small requests per second are sent to Michel's Tools (and, if a CDN such as Cloudflare or Bunny is in front, to the CDN's nearest data centre) while you keep this window open. Nothing you type or any file is used, and nothing is stored on the server.

Tip: press I notice a problem now (or the M key) the moment something freezes for you. The report then tells you whether the network was really responsible at that moment.

What this can and cannot see: it measures at the web level, so lost packets cannot be counted directly. They show up as delay jumps and missing answers, which is what you feel.
