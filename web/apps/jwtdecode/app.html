JSON Web Token (JWT)

Paste a token (with or without "Bearer ") to read its header, payload and times. A token is only encoded, not encrypted: anyone who has it can read it. Do not paste a token that is still valid and gives access to something real; use a test token or one that has expired. The reading is done in your browser and nothing is sent anywhere.

    Check the signature

      Use the PUBLIC key (or a certificate) for RS, PS and ES tokens, or the shared secret for HS tokens. Never paste a private key into a website: it is refused here. Checking needs the browser's crypto, which only works on https pages and on localhost.
