One TCP connection: what limits it?

A TCP connection can only have one window of data in flight per round trip, so the window and the delay cap its speed however fast the line is. The default 64 KiB window is the largest one without window scaling. Packet loss lowers the speed further (the Mathis formula, an estimate).
