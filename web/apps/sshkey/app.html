An SSH public key, certificate or key file

Shows the key type and size, the SHA-256 and MD5 fingerprints exactly as ssh-keygen -l prints them, the picture ssh-keygen -lv draws, and what looks weak. It reads public keys (.pub), OpenSSH certificates (-cert.pub), authorized_keys and known_hosts lines with their options, and RFC 4716 files. Everything is read in your browser and nothing is sent.

Private keys: please do not paste one anywhere you do not have to. If you give this tool an OpenSSH private key file it reads only the public key that the file stores in clear text at its start; the private part is never decoded or shown. A private key in the older PEM form is refused: run ssh-keygen -y -f yourkey to print its public key.
