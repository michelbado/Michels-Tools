HTTP response headers

Paste the response headers of a web page: from curl -I https://example.com (or curl -sv), or from your browser's developer tools (Network tab, click a request, Response Headers). The tool checks the security headers, cookies, caching, CORS and what the server gives away. It works only on what you paste: it makes no request, nothing is sent anywhere, and cookie values are never shown or copied. Headers can still reveal internal host names, so share the result with care.
