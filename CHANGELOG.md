# Changelog

## 1.0.3

- **Games folder** (`games`, new, the seventh folder): six small games for a short break, all drawn by the page itself (no pictures or libraries from elsewhere) and running in the browser: **Blocks** (`blocks`, falling pieces), **Mines** (`mines`, three sizes, first click always safe), **Pinball** (`pinball`, one table, three balls), **Road Racer** (`racer`, arcade driving against the clock), **Pool** (`pool`, 8-ball against the computer or a second player on the same screen) and **Bird Hunt** (`birdhunt`). Sound is off until the player switches it on. Best scores are kept in the visitor's own browser and never sent. A game pauses when its window is not in front. Set `games = false` in `tools.conf` to leave the folder out. See [Games](docs/tools.md#games-games).
- **Locked tools.** In `tools.conf`, a tool or a whole folder can now say `locked` instead of `true` or `false`: it stays visible with a padlock, and clicking it asks for a shared **access code** (`lock.code`). The check is made by the server: a locked tool's files and server calls answer `401` until the code has been entered. A correct code sets a cookie that lasts `lock.hours` hours (12 by default); changing the code logs everybody out. Wrong codes are counted and slowed down (8 from one address in 10 minutes, 120 overall). A locked tool with no code, or a code shorter than 4 characters, stops the program at startup. A "Lock again" entry in the Tools menu forgets the code and closes the locked tools. See [Locking tools](docs/configuration.md#locking-tools). It keeps casual visitors out; it is one shared code, not a user system.
- **Search in the Tools menu.** A search box at the top of the Start menu finds tools by name, folder and everyday words ("wifi", "checksum", "compress image"), forgives small typos, shows each result's folder and padlock, and opens the best match with Enter. `Ctrl+K` opens it from anywhere. It only lists tools that are on and visible on this server, and everything runs in the page.
- **Connection Quality now shows three separate results:** **Latency** (how long answers take: the typical time, best, 95% and worst; a figure, not a verdict), **Speed** (download and upload in Mbit/s) and **Quality** (steadiness). Speed used to be a word for the latency ("Close", "Far away"); it is now what you would expect, the data rate. It is measured over one connection to the server, always in the quick test, and the visitor chooses how much data it may use: **No transfer** (0 MB), **Light** (at most 15 MB, the default) or **Full** (at most 150 MB). It stops as soon as the speed is steady, so a slow line uses only a few MB; when the limit stops it first, the result reads "at least X Mbit/s" and the data used is shown. On a phone connection or with data saver on, the browser's hint switches the test off until the visitor chooses. An optional "my plan" field gives the speed a verdict (near, below, far below the plan); without it there is no verdict, because there is no scale. The upload is timed from the bytes the server confirms (the probe answers carry a count), not from the browser's own progress. Quality now also drops by one or two steps when the delay grows a lot while the line is busy. The text and HTML reports have the same three parts. `/api/download` allows up to 100 MB and `/api/upload` up to 50 MB (both ended early by the page).
- **Certificates folder** (`certs`, new, the fourth folder; the Certificate Decoder moves into it, so Network Tools has ten tools): everything runs in the browser, and nothing added, pasted or opened is sent anywhere.
  - **Certificate Package Checker**: drop a whole package (certificate, key, CA bundle, PFX, request; files are recognised by their content) and get one plain-language verdict: does the key match the certificate and the request, is the chain complete and in the right order (a missing intermediate is named, with the download address from inside the certificate), dates, names (wildcards, optional host name test), key size, weak signatures, PFX protection, each with a "what to do" line.
  - **Certificate Converter**: PFX with a password (modern AES-256, or old-compatible 3DES / SHA-1) or **without a password** (with a warning), fullchain and CA-bundle PEM files in the right order, certificate, chain and key in one PEM, key formats (PKCS#8, traditional, password-protected, DER), DER, P7B, and ready file sets with configuration lines for nginx, Apache, HAProxy, IIS and Tomcat. Each result is read back as a self-check and comes with the same operation as an `openssl` command; download one by one or as a ZIP.
  - **CSR & Key Generator**: a new key (RSA 2048/3072/4096, EC P-256/P-384) and a request with names, wildcards, IP and email addresses, made in the browser (needs https), optional password for the key.
  - **OpenSSL Command Helper**: about 25 common tasks as the exact `openssl` command with explanations; runs nothing.
  - Old formats open too: PFX files made by old Windows and Java (Triple-DES, RC2) and keys protected the old OpenSSL way, using small pure implementations written for this project (no new third-party library). Private keys and PFX files are held back until the visitor ticks "I understand" after a notice that the page does not collect or send them, that putting a private key into a web page is generally not advised and that `openssl` on your own computer is preferable; everything stays in memory and a "Wipe everything" button clears it. The tools do not check revocation or whether a browser trusts the root. The Certificate Decoder's note on certificate lifetime now also mentions the 200-day limit for public certificates issued after 15 March 2026.
- **Privacy notice:** mentions the one small cookie that entering the access code sets (only on a server that locks tools).

## 1.0.2

- **Eight new tools in Engineering Tools** (now fifteen), all running in the browser; nothing typed, pasted or opened is sent anywhere:
  - **JSON Formatter & Validator** (`jsonfmt`): exact line and column of a mistake in plain words, numbers and strings kept exactly as written, duplicate-key and rounding warnings, repair of the usual mistakes, path lookup.
  - **Text Compare** (`textdiff`): smallest set of line changes, changed words marked, unified diff to copy or save.
  - **Base64 & URL Encoder** (`encodetool`): Base64 (standard and URL-safe), percent-encoding, hexadecimal, HTML entities and \u escapes; binary results can be saved as a file.
  - **Hash & Checksum** (`hashcalc`): MD5, SHA-1/256/384/512, CRC-32, CRC-32C, Adler-32 and HMAC of text or a file, and a check against a hash you were given.
  - **Timestamp Converter** (`timeconv`): Unix time in any unit, dates, time zones with daylight-saving gaps and repeats explained, and the Windows, .NET, Excel and Apple epochs.
  - **Password & UUID Generator** (`passgen`): unbiased random passwords, UUID v4 and v7, ULID and tokens.
  - **Regex Tester** (`regextest`): JavaScript regular expressions with highlighted matches, groups and a replacement preview; matching is stopped after 2 seconds.
  - **QR Code Maker & Reader** (`qrcode`): codes for text, Wi-Fi, e-mail, phone, SMS and contact cards as PNG or SVG; reads a code from a picture without opening anything.
- **Upgrading:** the new tools are on unless `tools.conf` lists them as `false`; `deploy/tools.conf.example` shows their names.
- A test now fails if two tools share an id or a title.

## 1.0.1

- **New tools**, all of which run in the browser and only read what you paste or type (nothing is sent anywhere):
  - **SPF, DKIM & DMARC Reader** (`mailauth`, Network Tools): explains pasted DNS records in plain words and finds mistakes, including the real size of a DKIM key.
  - **MTU & MSS Calculator** (`mtucalc`, Network Tools): the largest packet through PPPoE, GRE, IPsec, WireGuard, VXLAN and similar layers, and the TCP MSS to set.
  - **HTTP Header Reader** (`httphdr`, Troubleshooting): checks pasted response headers for security headers, cookies, caching and CORS problems.
  - **Engineering Tools folder** (`engineering`, new), seven tools for developers, sysadmins and network engineers: **URL Parser**, **JWT Decoder**, **Basic Auth Generator**, **XML & JSON Converter**, **Crontab Generator**, **chmod Calculator** and **Color Converter**.
  - **Image Tools folder** (`images`, new): **Photo Info & Privacy (EXIF)** (`imgexif`) reads the hidden data in a JPEG, PNG or WebP (camera, date, exact location, serial numbers, owner names), lets you edit, add or remove any of it (date taken, artist, copyright, description, camera, location; it also works on a picture with no metadata), and saves a copy without re-compressing the picture; the new file is checked before download. **Resize / Crop** (`imgresize`) crops, turns, resizes and saves as JPEG, PNG or WebP. Both run in the browser and upload nothing. More in the same folder: **Blur / Redact** (`imgblur`: pixelate, blur or black out parts of a picture, checked before saving), **Convert & Compress** (`imgconvert`, including "smaller than N KB"), **Watermark** (`imgwatermark`: text or logo), **Batch Pictures** (`imgbatch`: resize, convert, remove hidden data or mark many pictures into one ZIP) and **Favicon & Icon Generator** (`imgfavicon`: `favicon.ico`, PNG sizes, manifest and HTML lines).
  - **Reference folder** (`reference`, new): seven look-up cards with a search box: Port Reference (moved here from Network Tools), DSCP & QoS Values, HTTP Status Codes, DNS Record Types, ICMP Types, TCP Reference and IPsec Reference (Diffie-Hellman groups, which DH group matches which encryption and hash, algorithms and the bytes they add to each packet).
  - **MTU & MSS Calculator:** IPsec ESP with AES-CBC and HMAC-SHA-384 or HMAC-SHA-512 added.
- **Phones:** the Tools menu now opens one folder at a time and scrolls, so a long folder no longer runs off the top of the screen. On wide screens the pop-out list is limited to the screen height and scrolls as well.
- **Upgrading:** a tool that is not listed in `tools.conf` is on. To switch the new tools off, add their names (for example `mailauth`, `mtucalc`, `httphdr`, or the folders `reference`, `engineering` and `images`) set to `false`; `deploy/tools.conf.example` lists them. Port Reference now sits in the `reference` folder, so `network = false` no longer hides it.
