# Tools

Everything opens from eight folders on the desktop (or from the **Michel's Tools** menu at the bottom left). Each tool has an **id**;
that is the name you use in [`tools.conf`](configuration.md#choosing-which-tools-to-offer-toolsconf) to switch it off. The folder ids are
`network`, `pdf`, `trouble`, `certs`, `engineering`, `images`, `reference` and `games`.

**Finding a tool.** Open the Start menu and type in the search box (or press `Ctrl+K`): it matches tool names, folder names and everyday words such as "wifi", "checksum" or "compress image", and forgives small typos. Enter opens the best match.

**Where the work happens.** Except where it says "uses the server", a tool runs **inside the visitor's browser**: nothing typed, pasted
or opened is sent anywhere. The server only serves the files. What the server does see and store is described in
[Server behaviour](server.md).

## PDF Tools (`pdf`)

All of these work on the file in the visitor's browser. The original file is never changed: the result is a new download.

| id | Tool | What it does |
|---|---|---|
| `pdfinfo` | PDF Info | Who made the file and with which program, when it was created and changed, whether it was edited after it was first saved, and what it contains (signatures, attachments, scripts, forms). |
| `pdfverify` | Verify Signatures | Checks that each digital signature is mathematically valid and that the document has not changed since signing. It **does not** check whether the signer's certificate is trusted or revoked, and the page says so. |
| `pdfmeta` | Metadata | Read, change or remove the details stored in a PDF (title, author, program, dates, hidden properties, older saved versions). |
| `pdfstamp` | Add Image / Signature | Places a picture (for example a scanned signature) on a page. It is a picture, **not a digital signature**, and the page says so. |
| `pdfwatermark` | Watermark & Page Numbers | Adds a text or picture watermark, page numbers, or a header and footer (any language). |
| `pdfpages` | Split / Extract Pages | Keep only some pages, or split into several files (every N pages, each page, or at chosen ranges). |
| `pdfmerge` | Merge PDFs | Join several PDFs, optionally choosing pages from each. |
| `pdforganize` | Organize Pages | Reorder, rotate, delete, duplicate and insert blank pages. |
| `pdfcrop` | Crop / Resize Pages | Cut margins by dragging a box, trim empty edges automatically, or change the page size (A4, Letter and others). Cropping hides but does not erase. |
| `pdfredact` | Redact | Blacks out parts of a PDF **for good**. Draw boxes by hand or search the text (a word or phrase, e-mail addresses, phone numbers, long numbers). Every page with a box is drawn to a picture with the boxes burned in and put into a new file, so the hidden text no longer exists in it. The new file is checked with the PDF reader itself (a changed page must hold no text) and nothing is downloaded if it fails; a searched word that still appears on a page without a box is reported. Pages without boxes are copied unchanged. A found match is covered together with the whole piece of text it is in, to be safe. Scanned pages have no text to search, so draw their boxes by hand. | `pdfimages` | Images / PDF Converter | Pictures to PDF (one per page, with page size, direction and border choices) and PDF pages to pictures (results are kept in browser memory, capped at 600 MB; saved as a ZIP). |
| `pdfextract` | Extract Content | Take out the text, the pictures and the attached files of a PDF. |

Known limits: merging, organising and resizing can drop links, bookmarks and form fields; changing a signed PDF makes its signature show as
changed (the tools warn about this).

## Troubleshooting (`trouble`)

| id | Tool | What it does |
|---|---|---|

| `browsercaps` | Browser Capability Report | Lists what the browser and device can do and whether the tools here will work. Makes no request. |
| `httphdr` | HTTP Header Reader | Paste the response headers of a web page (`curl -I`, `curl -sv`, or the browser's developer tools). It makes no request. |

## Certificates (`certs`)

All of these run **inside the visitor's browser**: nothing added, pasted or opened is sent anywhere, and the server never sees a file. Files and passwords are kept in the page's memory only (never in storage, in the address or in a report), and a **Wipe everything** button removes them. Reading a **private key** or a **PFX** file needs a deliberate step: the visitor must tick "I understand" after reading a notice that says the page does not collect or send what is added, that putting a private key into any web page is generally not advised, that a tool on your own computer such as `openssl` is preferable, and that continuing is at their own risk. The files are recognised by what is inside, not by their names (PEM, DER, PFX/P12, P7B, CSR, public keys, keys in every common format, old-style encrypted keys), including very old PFX files (RC2, Triple-DES) that most web tools cannot open. Revocation (OCSP/CRL) and a list of trusted root certificates are not included, so these tools prove that a package fits together but do not say whether a browser trusts its root.

| id | Tool | What it does |
|---|---|---|
| `certcheck` | Certificate Package Checker | Drop everything you received (certificate, key, CA or CA-bundle file, PFX, request) and get **one verdict** with plain explanations and a "what to do" line for every problem: does the key match the certificate (and the request), is the chain complete and in the right order (missing intermediate, wrong order, extra certificates; each signature is checked, and the download address written inside the certificate is shown), dates (expired, not yet valid, expiring soon, an intermediate that expires first), names (wildcards, an optional host name to test), key size, weak signatures, key usage, PFX protection. Locked files (encrypted keys, PFX) ask for their password. Report as text. |
| `certconvert` | Certificate Converter | Makes the files you need from a package: a **PFX** with a password (modern AES-256, or old-compatible 3DES / SHA-1 for old Windows and Java) or **without a password** (with a warning), fullchain and CA-bundle PEM files in the right order, certificate, chain and key in one PEM (HAProxy), the key in another format (PKCS#8, traditional, password-protected, DER), DER certificates, P7B, and ready sets of files with configuration lines for nginx, Apache, HAProxy, IIS and Tomcat. Every result is read back as a self-check, comes with the same operation as an `openssl` command, and can be downloaded one by one or as a ZIP. |
| `certcsr` | CSR & Key Generator | Makes a new key (RSA 2048/3072/4096, EC P-256/P-384) and a certificate request in the browser, with names (host names, wildcards, IP and email addresses), subject fields and an optional password for the key. Needs `https` or `localhost` (the browser's own cryptography); the request is checked after it is made. |
| `certdecode` | Certificate Decoder | Reads certificates, chains and certificate requests (CSRs) and checks the signatures in the browser. **Private keys are refused.** |
| `opensslhelp` | OpenSSL Command Helper | About 25 common certificate tasks (read, match, verify a chain, convert, create) as the exact `openssl` command with your file names filled in, a note for each command and the meaning of every part. It runs nothing and sends nothing; every command is tested against a real OpenSSL. |

## Image Tools (`images`)

Tools for pictures. All of them run in the browser: the picture is read from the file you open, nothing is uploaded, and the original file is never changed (you save a new copy). Further image tools will be added to this folder.

| id | Tool | What it does |
|---|---|---|
| `imgexif` | Photo Info & Privacy (EXIF) | Opens a JPEG, PNG or WebP and shows the hidden data inside it: camera and lens, date and time, exposure settings, and above all **where it was taken** (GPS, shown as numbers; the tool makes no map request), serial numbers, the owner's or photographer's name, comments, an embedded thumbnail, and other data such as XMP, IPTC and text notes. ## Games (`games`)

Small games for a short break. They run in the browser, need nothing from the server after the page has loaded, and use no pictures or
libraries from anywhere else: everything on screen is drawn by the game itself. **Sound is off** when a game opens; the **Sound** button
switches it on. Best scores are kept in the visitor's own browser and are never sent. A game pauses by itself when its window is not the
one in front, is minimised, or the browser tab is hidden. On a phone the games show their own buttons or react to taps. To leave the
folder out, set `games = false`; to keep them visible but behind the access code, set `games = locked` (or lock a single game, for example `pool = locked`): see [Locking tools](configuration.md#locking-tools).

| id | Game | What it is |
|---|---|---|
| `blocks` | Blocks | Falling pieces: fill a whole row to clear it. Shows the next three pieces and where the piece will land; one piece can be kept for later. Arrow keys move and turn, Space drops, C keeps, P pauses. The pieces fall faster every ten rows. |
| `mines` | Mines | Open every square that hides no mine; a number tells how many mines touch a square. Three sizes (9 x 9, 16 x 16, 30 x 16). The first click is always safe.
